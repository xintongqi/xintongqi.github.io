Basics

Some quick MATLAB notes, starting with the basics. Run commands directly in the Command Window, or save them in a .m script to run again later.

x = 5;                    % 'double' (default numeric type)
name = "Amy";             % string scalar
letters = 'Amy';          % character vector
isReady = true;           % logical value
class(x)                  % check type
fprintf('x = %.2f\n', x)  % formatted output: x = 5.00

who                       % list workspace variables
whos                      % also show sizes and types
clear x                   % remove just x
clc                       % clear the Command Window, keeping variables
pwd                       % current folder

Variable names are case-sensitive: x and X are different. Use ... at the end of a line to continue a long expression on the next line.

Arrays and Matrices

Spaces or commas separate columns; semicolons separate rows. All rows in a matrix need the same length.

row = [1 2 3];                  % 1-by-3 row vector
col = [1; 2; 3];                % 3-by-1 column vector
A = [1 2 3; 4 5 6];             % 2-by-3 matrix

steps = 0:2:10;                 % [0 2 4 6 8 10]: start:step:end
points = linspace(0, 1, 5);     % 5 evenly spaced points, including both ends
Z = zeros(2, 3);                % 2-by-3 zeros
O = ones(2, 3);                 % 2-by-3 ones
I = eye(3);                     % 3-by-3 identity matrix

size(A)                         % [2 3]
size(A, 1)                      % 2 rows
numel(A)                        % 6 elements
length(A)                       % 3: largest dimension, not total elements

B = [A; 7 8 9];                 % append a row
C = [A, [7; 8]];                % append a column
reshaped = reshape(1:6, 2, 3);  % [1 3 5; 2 4 6], filled column by column

Indexing

Indices start at 1. Use parentheses to select elements, : for a range or an entire dimension, and end for the last index in that dimension.

A = [10 20 30; 40 50 60];
A(2, 3)              % 60: row 2, column 3
A(1, :)              % [10 20 30]: entire first row
A(:, 2)              % [20; 50]: entire second column
A(:, 1:2)            % first two columns (both endpoints included)
A(end, end)          % 60

% A single index traverses columns, top to bottom.
A(3)                 % 20
A(:)                 % [10; 40; 20; 50; 30; 60]

mask = A > 30;       % logical array of the same size as A
selected = A(mask);  % [40; 50; 60]
A(A > 30) = 0;       % replace matching elements
A(:, 2) = [];        % delete the second column

Operations

*, /, and ^ are matrix operations. Use .*, ./, and .^ to operate on individual elements. Addition and subtraction already work element by element.

A = [1 2; 3 4];
B = [5 6; 7 8];
A * B                           % matrix product: [19 22; 43 50]
A .* B                          % element-wise product: [5 12; 21 32]
A ^ 2                           % A * A
A .^ 2                          % square each element: [1 4; 9 16]
A ./ B                          % divide corresponding elements
A + 10                          % add 10 to every element
A.'                             % transpose without complex conjugation
A'                              % conjugate transpose (same for real numbers)

% Solve A*x = b with backslash.
b = [5; 11];
x = A \ b;                      % [1; 2]

sum(A)                          % column sums: [4 6]
mean(A, 2)                      % row means: [1.5; 3.5]
sum(A(:))                       % sum of every element: 10
[value, index] = max([3 9 4]);  % value = 9, index = 2

For matrix multiplication, the inner dimensions must match. Element-wise operations need compatible sizes; matching sizes are the simplest case. A row plus a column can expand into a matrix, so check shapes when a result looks unexpected.

Scripts and Functions

A script runs commands in the workspace it is called from. Save this as first_plot.m, then type first_plot in the Command Window while its folder is current.

% first_plot.m
x = linspace(0, 2*pi, 100);
y = sin(x);
plot(x, y)
grid on

A function has its own workspace and receives inputs explicitly. Save this function in rectangleStats.m, matching the function name. 

function [area, perimeter] = rectangleStats(width, height)
    area = width * height;
    perimeter = 2 * (width + height);
end

Call it from the Command Window or another script. The file must be in the current folder or on the MATLAB path.

[a, p] = rectangleStats(3, 4);  % a = 12, p = 14
[a, ~] = rectangleStats(3, 4);  % ignore the second output

% Anonymous functions are useful for short expressions.
square = @(x) x.^2;
square([1 2 3])                 % [1 4 9]

Conditions and Loops

Use == to compare values and ~= for “not equal.” && and || short-circuit scalar logical conditions; & and | combine logical arrays element by element. 

score = 75;
if score >= 90
    disp("Great")
elseif score >= 60
    disp("Pass")
else
    disp("Try again")
end

values = [2 5 8];
if any(values > 7)
    disp("At least one value is above 7")
end
if all(values > 0)
    disp("All values are positive")
end

squares = zeros(1, 5);  % allocate space before the loop
for k = 1:5
    squares(k) = k^2;
end
% The same calculation can be written as (1:5).^2.

n = 1;
while n < 10
    n = n * 2;
end                     % n = 16

break exits a loop; continue skips to the next iteration. For a matrix-wide condition, use something like all(A(:) > 0) to get one logical value.

Plotting

For a simple line plot, give plot two vectors with the same number of elements. Use hold on to add a second curve to the same axes.

x = linspace(0, 2*pi, 200);
figure
plot(x, sin(x), 'b-', 'LineWidth', 1.5)
hold on
plot(x, cos(x), 'r--', 'LineWidth', 1.5)
hold off
xlabel('x (radians)')
ylabel('Value')
title('Sine and cosine')
legend('sin(x)', 'cos(x)', 'Location', 'best')
grid on

% Run separately for a scatter plot or histogram.
figure
scatter([1 2 3], [2 5 4])
figure
histogram([1 1 2 3 3 3 4])

Call figure to start a new figure window and close to close the current one.

Saving and Loading

MAT-files preserve MATLAB variables. CSV files are useful for exchanging rectangular data. These examples write files in the current folder and overwrite files with the same names.

x = 1:5;
y = x.^2;
save('matlab_guide_example.mat', 'x', 'y')
loaded = load('matlab_guide_example.mat');  % load into a structure
loaded.x                                    % access a saved variable

M = [1 10; 2 20; 3 30];
writematrix(M, 'matlab_guide_example.csv')
M = readmatrix('matlab_guide_example.csv');

% Tables give columns names and can hold different types of data.
T = table(["Amy"; "Sam"], [90; 85], ...
    'VariableNames', {'Name', 'Score'});
T.Score                                     % access one column
writetable(T, 'matlab_guide_scores.csv')
T = readtable('matlab_guide_scores.csv');

Common Gotchas

  • A(0) is invalid: indexing starts at 1.
  • 1:3 includes 3. With a different step, the endpoint is included only if reached.
  • = assigns; == compares.
  • Use x.^2 when squaring each value of a vector.
  • A row vector and a column vector have different shapes. Check size when debugging.
  • Avoid variable or file names such as sum, plot, or mean; they can hide built-in functions. which plot -all helps find name conflicts.
  • Scripts can depend on variables left in the workspace. Define their inputs so they also run in a fresh session.
  • Click beside a line number in the Editor to set a breakpoint and inspect variables while paused.
